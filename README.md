# Emberdeep

A tiny torchlit roguelike in a single HTML file. Open `index.html` in a browser and descend.

- Move with arrows / WASD / hjkl (`yubn` for diagonals), or tap a direction on the map or use the on-screen pad.
- Bump into monsters to fight. `Q` quaffs a potion, `R` reads a scroll of mapping, `>` takes the stairs down.
- Levels are procedurally generated from a seed; monsters get nastier the deeper you go. Your best score is kept in local storage.
